🛡️ ScaBase

开源软件成分分析（SCA）漏洞查询 · 基于 OSV + NVD · 支持 Maven GAV / NPM / PyPI / Go

离线模式 · 仅本地漏洞库
支持的输入格式
  • pkg_list 格式（推荐）：ecosystem|package|version，与 data/pkg_list.txt 一致。Maven 的 package 为 groupId:artifactId。 例：maven|com.alibaba:fastjson|1.2.24、npm|lodash|4.17.20、 pypi|requests|2.20.0、go|github.com/gin-gonic/gin|1.6.0。
  • GAV（Maven 坐标）：groupId:artifactId:version，例 org.springframework.boot:spring-boot-starter-web:2.7.0；省略版本为 groupId:artifactId。
  • 简写：ecosystem:package@version，例 PyPI:requests@2.20.0。
  • CVE 编号：直接输入 CVE-2021-44228，可反查本地漏洞库中受该 CVE 影响的组件。
  • 以 # 开头的行视为注释，空行自动忽略。支持生态： maven / npm / pypi / go（并自动映射为 OSV 生态名）。

结果默认以 CVE 编号 为主标识展示（GHSA 等作为次要别名）， 一条记录关联多个 CVE 时会全部列出；可用工具栏按 CVE 过滤、切换「按 CVE」聚合视图。

开源软件支持力度与活跃度

汇总各开源组件的社区支持力度与活跃度（维护健康度）：由 community_report.py 基于 GitHub / deps.dev / 各生态 registry 信号评分， 按 A/B/C/D 四级呈现。评分遵循「未知即风险」——缺失信号按保守扣分， 已归档 / 停止维护直接判 D · 弱。

查询方式与数据说明
  • 输入格式与漏洞查询完全一致：ecosystem|package|version、 groupId:artifactId:version、ecosystem:package@version； # 开头为注释。
  • 版本不是必须的：社区健康度是「组件级」评估，未写版本时按同名组件匹配， 并在卡片上标注报告实际采用的版本。
  • 未收录的组件：健康度数据由 community-health.yml 按 pkg_list.txt / pkg_list_popular.txt 采集生成，未覆盖的组件会单独列出， 可复制到清单后重新参与采集。
  • 查询后仍可用下方「等级 / 搜索 / 排序」做二次筛选；清空输入框并查询即回到全量浏览。
