# 2026-10-15

## 开源引入评估 · 落地增强（行业场景）

基于用户给出的开源治理背景，扩展 `add-oss-intake-evaluation` 变更，新增 6 个能力 delta spec：
`native-dependency-parsing` / `community-support` / `security-baseline` /
`ai-script-generation` / `vuln-impact-patrol` / `toolchain-integration`，
并扩写 `component-health`（治理信号采集）、`intake-gate`（平台产物导出）、`build-delivery`（准确率门禁）。

### 新增代码

- `oss_intake/depfile.py`：原生依赖文件解析（pom/gradle/npm 系 4 种/pypi 系 4 种/go/cargo/composer/gem），
  统一输出 PURL + direct/scope/version_req/pinned；`discover()` 跳过 node_modules 等目录。
- `oss_intake/community.py`：社区支持力度 0-100 + A/B/C/D，缺失信号按「未知即风险」扣分；
  archived 直接压到 D。
- `oss_intake/baseline.py`：32 条声明式基线（standalone 24 + embedded 8），
  `run_check` 输出 PASS/FAIL/UNKNOWN；配置项未声明时对 set/eq/contains/regex 按空值判 FAIL，其余判 UNKNOWN。
- `oss_intake/scriptgen.py`：三目标脚本生成（sreops sh / codescan yaml+py / 通用 py），
  模板引擎 + 可选 LLM（`SCABASE_LLM_ENDPOINT`，失败回落模板）+ lint；
  FORBIDDEN 只保留无歧义破坏性指令（"shutdown"/"reboot" 会误伤描述文字，已移除）。
- `oss_intake/verify.py`：准确率回归，默认阈值 0.9，UNKNOWN 计入漏检。
- `oss_intake/patrol.py`：按应用聚合巡检 + 工单（KEV/CVSS 定级，7/15/30/90 天期限）+ 增量对比 + 共性风险。
- `oss_intake/integrations/depinfo.py`：台账导入（purl/gav/eco 三形态）→ 资产模型；结论回传默认脱敏。
- `oss_intake/integrations/cicd.py`：SARIF 2.1.0 / JUnit XML / MR 评论 / 四档退出码。

### 关键改动

- `assets.build_inventory` 支持 app 级 `gavs` / `purls`（depinfo 台账形态，无 SBOM 文件）。
- `scoring.evaluate` 结果新增 `community` 字段；策略新增 `community_deny_grades`（默认空，不破坏既有测试）。
- CLI 新增 `scan / patrol / baseline / genscript / verify / depinfo`，`gate` 新增 `--sarif/--junit/--comment`。
- 新增示例：`examples/deps/*`（5 种依赖文件）、`baseline-catalog.json`、`accuracy-cases.json`（64 例）、`depinfo-export.json`。
- 新增测试 7 个文件（约 60 条用例），CI 增加准确率门禁与脚本归档步骤。
