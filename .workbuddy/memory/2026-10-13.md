## 网站查询结果改为以 CVE 编号为主键展示

改动文件：`index.html`、`assets/app.js`、`assets/style.css`、`readme_zh_cn.md`

- `normalize()` 重写：从 OSV id + aliases + NVD id 收集**全部** CVE（原来只取第一个别名当小标签），
  生成 `cves[]` / `primaryCve` / `otherIds`，以 CVE 作为展示主标识并链到 NVD，
  GHSA 等退为次要别名标签。
- 新增 `dedupe()` 按 CVE 集合合并：指向同一组 CVE 的多个 GHSA advisory 合并为一条
  （lodash 5 条 → 3 条），`mergeVuln` 合并 CWЕ/refs/severity，主 CVE 沿用 NVD 富化对应的那个，
  避免标题与 CVSS 描述错位。
- 新增结果工具栏：`#filter`（CVE/关键词过滤，按 CVE 前缀过滤时只保留命中的 CVE）、
  `#sevFilter`、`#sortBy`（严重度/CVE/发布时间/组件名）、「按组件 / 按 CVE」视图切换、
  「复制 CVE 清单」。
- 新增「按 CVE」聚合视图 `cveGroups()` + `renderCveCard()`：以 CVE 为聚合键，展示受影响组件 chips。
- 输入解析新增 CVE 直查：`parseLine` 识别 `CVE-xxxx-yyyy`，`cveLocalHits/resolveCve` 反查本地库，
  未命中时回退 OSV `/v1/vulns/{id}`，再失败给出 NVD 链接。
- 修复：`recordItems` 原来硬读 `rec.entry`，导致 init 里统计漏洞数恒为 0；改为兼容两种形态。
- 修复：清空按钮未重置 filter/sev/sort，导致下次查询结果为空。

校验方式：用 jsdom + 本地 vulns.json 桩掉 fetch，跑通渲染/过滤/排序/复制
（脚本在 /tmp/scabase_dom_test.js、/tmp/scabase_dom_test2.js，jsdom 装在
/Users/block/.workbuddy/binaries/node/workspace）。

## 支持 GitHub Pages 与 Docker 内网部署

新增文件：`Dockerfile`、`docker/nginx-default.conf`、`docker/10-env-config.sh`、
`docker-compose.yml`、`.dockerignore`、`.github/workflows/docker.yml`、`assets/config.js`

- 镜像：`nginx:1.27-alpine`，监听 **8080**（非 root 运行）；gzip 使 vulns.json 2.8MB → 293KB；
  `/healthz` 供 HEALTHCHECK 用；数据目录可用 `-v` 挂载热更新，无需重建镜像。
- 运行时配置：`docker/10-env-config.sh` 放在 `/docker-entrypoint.d/`，容器启动时按环境变量
  生成 `assets/config.js`（SCABASE_OFFLINE / OSV API / NVD 前缀），无需重新构建镜像。
- 前端：`app.js` 读 `window.SCABASE_CONFIG`；`offline=true` 时隐藏「强制实时 OSV」勾选框、
  显示离线标记，未知组件给出 `offlineMiss` 提示卡片而不是发网络请求（实测外部请求 0 次）。
- 修复：无漏洞但带 note 的条目原先会被 `visibleResults()` 过滤掉，改为保留卡片；
  有 note 时不再显示误导性的「✓ 未发现已知漏洞」。
- CI：`.github/workflows/docker.yml` 参考 `/Users/block/code/blockai/.github/workflows/build-agtray.yml`
  —— setup-qemu + buildx + metadata-action + 阿里云仓库登录，`outputs: type=image,oci-mediatypes=false,push=...`、
  `provenance: false`、`sbom: false`、latest + 日期双标签；另加 `docker-offline-bundle` job
  用 `outputs: type=docker,dest=*.tar` 产出 amd64/arm64 离线包供纯内网 `docker load`。
- 注意：本机 buildx 默认 builder 会报
  `failed to update builder last activity time ... operation not permitted`（沙箱限制），
  本地构建改用 `DOCKER_BUILDKIT=0 docker build` 即可。
